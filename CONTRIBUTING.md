# Contributing to YARDSLOVESYOU

Thank you for your interest in contributing to **YARDSLOVESYOU** — a digital platform for sound design, instrumentals, digital audio products, and custom client track submissions. 

Whether you're reporting a bug, suggesting a new feature, or improving code, your support is highly appreciated!

---

## Code of Conduct

Please maintain a respectful, collaborative, and constructive environment when interacting with this repository.

---

## How Can I Contribute?

### 1. Reporting Bugs
If you encounter any issues (e.g., with the Stripe checkout, file uploads, or UI display):
* Check the existing **Issues** to see if the bug has already been reported.
* If not, open a new issue and include:
  * A clear description of the problem.
  * Steps to reproduce the bug.
  * Browser/device information and screenshots if applicable.

### 2. Suggesting Enhancements
Have an idea to improve the shop, audio previews, or the submission workflow?
* Open an issue with the tag **Enhancement** or **Feature Request**.
* Describe your idea clearly and explain how it enhances the user or artist experience.
